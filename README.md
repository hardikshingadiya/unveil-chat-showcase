# Unveil — Private & Anonymous Chat

Unveil is an Android chat application designed for private conversations and anonymous connections. It combines real-time messaging with anonymous matching, timed conversations, email verification, user search, and mutual reveal functionality.

> **Note:** This repository is a public project showcase. The Android source code is maintained in a private repository.

## ✨ Features

- 🔐 User registration and login
- ✉️ Email verification
- 💬 Real-time private messaging
- 👤 User search
- 🕵️ Anonymous user matching
- ⏱️ Timed anonymous conversations
- 🤝 Mutual reveal functionality
- 📱 Clean Android UI
- 📖 Built-in community guidelines and FAQs

## 📱 Application Flow

The main user journey includes:

1. Registration
2. Login
3. Email Verification
4. Chats
5. Private Chat
6. Anonymous Matching
7. Anonymous Chat
8. More & Guidelines

## 🛠️ Technology Stack

- **Language:** Kotlin
- **Platform:** Android
- **Authentication:** Firebase Authentication
- **Database:** Cloud Firestore
- **Messaging:** Real-time Firebase-based messaging
- **UI:** Android XML layouts
