ANDROID CHAT APPLICATION

Connect privately.
Chat anonymously.

Unveil is an Android chat application built around private conversations and short-lived anonymous chats, giving users a simple way to connect without immediately revealing their identity.

⬇ Download APK Explore the App

Source code is maintained in a private GitHub repository.

WHAT IT OFFERS

Built for real conversations

Unveil combines conventional private chats with a dedicated anonymous matching experience.

💬

Private Chat

Send and receive messages through individual conversations with online status and message timestamps.

👤

Anonymous Chat

Find another user for a short anonymous conversation without revealing identities immediately.

⏱️

Timed Conversations

Anonymous sessions are designed around a short two-minute conversation window.

🔐

Email Verification

Account registration includes email verification before the user starts using the application.

🔎

User Search

Search for users and access existing conversations from the chat interface.

🤝

Mutual Reveal

Anonymous users can choose to reveal their identities when both participants agree.
